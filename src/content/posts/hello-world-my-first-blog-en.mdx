## Why build a separate website?

Mostly, I wanted to keep things in one place.

Projects I've worked on, small tools I've built, and notes from development all need somewhere I can find them again. Anyone curious about what I'm doing can take a look, and it'll be easier for me to come back and find things later, too.

The blog serves the same purpose. Sometimes I solve a problem and think I'll remember the solution, only to look it all up again a while later. If I write down the problem, what I tried, and what eventually worked, at least I'll know where to start next time.

So there isn't an elaborate plan for this place yet. First, explain the projects clearly, then write a few notes that I'll find useful later.

## A small tool I've built

One project already on the site is [PixPage - Smart Element Picker Assistant](/en/projects/chrome-extension-en), a browser extension published on the Chrome Web Store.

It does something specific: select an element on a web page, extract its locator information, and organize that information into context you can send straight to an AI tool. For example, if you want to point out that “this button is in the wrong place,” you can include the element, its selectors, and the page information together, instead of relying entirely on a written description of where it is.

I'll keep refining this website, and there's plenty more I could write about PixPage. A separate post can cover how to use it and how it works. I'll keep this first one brief.
